# Dissertation on "Nifty 50 Trend Prediction using Financial News Data and Historical Nifty 50 Data"

**Author:** Dhanuja Bukkam

**University:** Goa University | Year: 2026

**Abstract:**
This dissertation examines whether financial news sentiment can improve Nifty 50 analysis when combined with market data. The study is motivated by the growing use of artificial intelligence and natural language processing in financial forecasting, alongside a gap in the literature on India-focused pipelines that connect domain-adapted financial sentiment models with downstream index-level prediction and external validation. To address this gap, the research develops a two-stage framework using Indian financial news and Nifty 50 data. In the first stage, a 2025 financial news dataset obtained from Zenodo was summarized using a BART model and pseudo-labelled using ‘ProsusAI/finbert’, after which the base model ‘Vansh180/FinBERT-India-v1’ was continued fine-tuned on the summarized dataset. The adapted model was evaluated on chronological 2025 validation and test splits and then compared with the base model on a separate manually labelled 2026 dataset of 104 Nifty-related news articles. In the second stage, article-level sentiment probabilities generated by the continued fine-tuned model were aggregated into daily sentiment-confidence features and merged with 2025 Nifty 50 data downloaded from the NSE website. Two ‘Random Forest Regressor’ models, one numerical-only and one sentiment-plus-numerical, were evaluated using time-series cross-validation and Mean Absolute Error. The continued fine-tuned model achieved overall accuracy of 89% and a macro F1-score of 0.84 on the held-out 2025 test split, and improved external accuracy from 50.00% for the base model to 69.23% on the unseen 2026 dataset. In the forecasting stage, the hybrid model reduced MAE only marginally from 0.0048432 to 0.0048371, while neutral sentiment remained the weakest classification class. The study concludes that continued fine-tuning is effective for Indian financial sentiment classification, but that sentiment-derived features contribute only modestly to next-day absolute return prediction under the present data and aggregation constraints. Future work should use larger manually labelled datasets, richer sentiment representations, and more advanced forecasting models.
Keywords: Financial Sentiment Analysis, FinBERT, Nifty 50, Stock Forecasting, NLP.
